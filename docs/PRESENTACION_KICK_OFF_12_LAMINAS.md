## Lámina 3 — La Organización Cliente

**Descripción**  
El cliente son **licorerías pequeñas en Piura** que trabajan con 1 o 2 personas (muchas veces el dueño es uno de ellos). Son negocios que venden bebidas y necesitan ordenar ventas, inventario y facturación.

**Misión**  
Atender bien al cliente, vender de forma ordenada y cumplir con la ley (SUNAT), para que el negocio sea rentable y sostenible.

**Visión**  
Ser un negocio moderno, con control de inventario, ventas rápidas y comprobantes electrónicos al día, para crecer y competir mejor.

---

## Lámina 4 — Descripción de la Necesidad (Problemática)

- **Ventas a mano:** Se anota en cuaderno o Excel; hay errores y se pierde tiempo (3–5 minutos por venta).
- **Sin boletas electrónicas:** No se emiten comprobantes como pide SUNAT; hay riesgo de multas.
- **Inventario descontrolado:** No se sabe bien qué hay en stock; se pierde dinero por productos vencidos o faltantes.
- **Pocos reportes:** No hay reportes claros de ventas ni de qué productos conviene comprar o promocionar.
- **Sin promociones ni fidelización:** No se pueden armar packs ni programas de puntos para clientes frecuentes.

**En números:** se estiman pérdidas de unos **S/ 33 000 al año** por estos problemas.

---

## Lámina 5 — Descripción de la Solución

Un **sistema web y app** que integra:

- **Punto de venta (POS):** ventas rápidas, búsqueda de productos, varias formas de pago.
- **Facturación electrónica:** boletas y facturas con SUNAT.
- **Inventario:** stock en tiempo real, alertas de stock bajo y productos por vencer.
- **Promociones y packs:** descuentos, combos y ofertas.
- **Reportes:** dashboard con ventas, productos más vendidos y alertas.
- **Inteligencia artificial:** recomendaciones de productos y predicciones sencillas para compras y promociones.

Todo pensado para que 1 o 2 personas puedan usarlo sin complicarse.

---

## Lámina 6 — Alcance y Exclusiones

**Qué sí incluye el proyecto**

- POS, inventario, facturación electrónica (SUNAT), promociones y packs, clientes y puntos, reportes y dashboard, usuarios con roles (Admin / Vendedor), sistema web y aplicación tipo POS.

**Qué no incluye (fuera de alcance)**

- Contabilidad completa, planillas, integración con bancos, tienda en línea (e-commerce), app para clientes finales, delivery, redes sociales.  
  Si en el futuro se pidiera algo de esto, sería un cambio de alcance acordado.

---

## Lámina 7 — Objetivos del Proyecto

**Objetivo general**  
Desarrollar e implementar un sistema web y app con apoyo de IA para que las licorerías pequeñas en Piura gestionen ventas, inventario, facturación y promociones de forma más rápida y ordenada, cumpliendo con SUNAT y mejorando la atención al cliente.

**Objetivos específicos (resumidos)**

1. Digitalizar las ventas (POS rápido).  
2. Automatizar boletas y facturas con SUNAT.  
3. Controlar inventario en tiempo real con alertas.  
4. Gestionar promociones y packs.  
5. Generar reportes y un dashboard útil.  
6. Tener programa de fidelización (puntos/clientes).  
7. Usar IA para recomendaciones y predicciones sencillas.  
8. Interfaz fácil de usar para 1–2 personas.

## Lámina 8 — Costos y Factibilidad Económica

**Presupuesto estimado (contexto: licencias gratuitas y desarrollo por practicante)**

| Concepto                    | Monto        | Nota |
|-----------------------------|-------------|------|
| Recursos humanos            | S/ 0        | Desarrollado por practicante (proyecto formativo). |
| Licencias de software       | S/ 0        | Uso de software libre y gratuito (ej. React, Spring Boot, PostgreSQL). |
| Infraestructura (1.º año)   | S/ 0 – 500  | Opcional: se puede usar el equipo del negocio; si se contrata hosting, costos bajos. |
| Hardware (POS, impresora)   | S/ 0 – 600  | Opcional: uso de PC/tablet e impresora existentes; solo si el cliente compra nuevo. |
| Otros (contingencias)       | S/ 0 – 200  | Mínimo (dominio, certificado SSL en plan gratuito, etc.). |
| **Total proyecto**          | **S/ 0 – 1 300** | Según si el cliente usa solo lo que ya tiene o invierte en equipo/hosting. |

**Factibilidad económica**  
- Al usar **licencias gratuitas** y un **practicante** como desarrollador, el **costo directo del proyecto para el cliente es muy bajo o nulo**.  
- El beneficio esperado sigue siendo alto: reducir pérdidas de **S/ 33 000/año** a menos de **S/ 5 000/año**.  
- Cumplir con SUNAT evita multas y permite vender a empresas que piden factura.  
- **Conclusión:** el proyecto es **muy factible** para la licorería porque la inversión es mínima y el retorno (menos pérdidas y más control) es grande.

## Lámina 10 — Factores Críticos de Éxito, Supuestos y Restricciones

**Factores críticos de éxito**  
- Que el cliente use el sistema todos los días.  
- Integración estable con SUNAT (comprobantes electrónicos).  
- Interfaz sencilla para 1–2 usuarios.  
- Capacitación básica y soporte al inicio.

**Supuestos**  
- El cliente tiene (o puede obtener) certificado y OSE para SUNAT.  
- Hay internet en el local (y se contempla modo offline para el POS).  
- El equipo dispone del tiempo acordado para reuniones y pruebas.

**Restricciones**  
- Presupuesto y plazo fijos (14 semanas).  
- Normativa SUNAT vigente.  
- Uso de tecnologías definidas en el proyecto (Spring Boot, React, PostgreSQL, etc.).

## Lámina 11 — Riesgos

| Riesgo                         | Qué hacemos para evitarlo o reducirlo                    |
|--------------------------------|----------------------------------------------------------|
| Problemas con SUNAT            | Probar pronto en ambiente de pruebas; diseño flexible   |
| Cambios de requisitos           | Metodología ágil; hablar seguido con el cliente          |
| Retrasos                       | Priorizar lo más importante; dejar margen en el plan     |
| Que no usen el sistema          | Capacitación; interfaz fácil; acompañamiento al inicio   |
