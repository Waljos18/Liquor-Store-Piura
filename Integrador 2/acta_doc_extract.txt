Propósito del documento
Este documento define la descripción general, los objetivos y los participantes del proyecto. Se relaciona principalmente con la autorización del inicio del proyecto.
Así mismo, este documento brinda una descripción de la situación actual, los requisitos de alto nivel, criterios de éxito, riegos y oportunidades.
Propósito / Justificación:
Implementar un Sistema Web y App Móvil con Inteligencia Artificial para Gestión Integral de Licorería que centralice y automatice los procesos clave de las licorerías pequeñas en Piura (ventas, inventario, facturación electrónica, promociones y reportes), reduciendo tiempos operativos (de 3-4 minutos a 30-45 segundos por venta), errores de registro y pérdidas económicas estimadas en S/. 33,000 anuales; a la vez que mejora el cumplimiento normativo con SUNAT, la precisión de inventario, la disponibilidad de información para la toma de decisiones y la experiencia de dueños, empleados y clientes mediante recomendaciones inteligentes y predicciones automatizadas.
Breve descripción del proyecto:
El proyecto desarrollará, configurará y pondrá en producción un Sistema Web y App Móvil con Inteligencia Artificial como solución integral para licorerías pequeñas, con perfiles y permisos por rol (Administrador/Vendedor). Incluirá levantamiento de requerimientos, diseño, desarrollo, pruebas, migración/carga inicial de datos, capacitación y acompañamiento post-implementación. La solución se desplegará en infraestructura en la nube o local, según decisión del cliente, con respaldos y medidas de seguridad acordes a la protección de datos personales. Tecnologías: React.js + Spring Boot + PostgreSQL + Python/ML. Duración estimada: 14 semanas.
Alcance preliminar del proyecto:
Incluye:
- Gestión de productos: registro, categorías, precios, stock mínimo/máximo, fechas de vencimiento.
- Punto de venta (POS): ventas rápidas, búsqueda de productos, aplicación automática de promociones, múltiples formas de pago, historial de ventas.
- Facturación electrónica: emisión de boletas y facturas electrónicas, integración con API de SUNAT, generación de XML y PDF, resumen diario de boletas (RCB).
- Control de inventario: actualización automática, alertas de stock bajo y productos próximos a vencer, gestión de compras y proveedores, movimientos de inventario.
- Promociones y packs: creación de packs, descuentos por porcentaje/monto/volumen, promociones temporales y por categoría.
- Clientes y fidelización: registro de clientes, historial de compras, sistema de puntos y programa de fidelización.
- Reportes y analytics: dashboard ejecutivo, reportes de ventas/inventario/rentabilidad, exportación a Excel/PDF, insights automáticos de IA.
- Inteligencia artificial: recomendaciones de productos, predicción de demanda, optimización de inventario, sugerencias de promociones, análisis de patrones, asistente virtual (chatbot).
- Administración: usuarios, roles, permisos, configuración de facturación, parámetros del sistema.
- Plataformas: Sistema Web (principal) y Aplicación POS (Electron). Integraciones: SUNAT, lectores de código de barras, impresoras térmicas.
(prioridad: Web + POS en fase 1).
Resultados esperados del proyecto / Beneficios:
Beneficios Operativos
- Reducción de tiempo de venta: De 3-4 minutos a 30-45 segundos por venta (reducción del 80%), permitiendo atender 4-6 veces más clientes con el mismo personal
-  Eliminación de errores: Errores en cálculos de precios, totales y cambio reducidos a < 1%
- Precisión de inventario: Aumento de precisión de inventario del 70% al >98%, reduciendo pérdidas por productos vencidos y desabastecimiento
- Automatización de procesos: Reducción de tiempo en tareas manuales de 2-3 horas/día a 30 minutos/día
Beneficios Económicos
- Reducción de pérdidas: Disminución de pérdidas anuales de S/. 33,000 a menos de S/. 5,000 (ahorro de S/. 28,000 anuales)
- Eliminación de multas: Cumplimiento 100% con normativas SUNAT, eliminando multas de S/. 3,000/año
- Aumento de ventas: Incremento estimado del 20-30% por mejor atención, disponibilidad de productos y acceso a mercado corporativo
- ROI positivo: Recuperación de inversión en 12-15 meses
Beneficios Estratégicos
- Cumplimiento normativo: 100% de comprobantes electrónicos emitidos correctamente, eliminando riesgos legales
- Competitividad mejorada: Capacidad de competir con establecimientos más grandes mediante herramientas tecnológicas modernas
- Toma de decisiones informada: Reportes y analytics con insights de IA para decisiones basadas en datos
- Escalabilidad: Sistema que crece con el negocio, desde operación pequeña hasta mediana
- Ventaja competitiva: Herramientas de IA normalmente disponibles solo para grandes empresas
Beneficios para Usuarios
- Facilidad de uso: Interfaz intuitiva diseñada para personal con conocimientos tecnológicos básicos
- Reducción de carga de trabajo: Automatización inteligente reduce decisiones manuales del dueño/empleado
- Mejor experiencia del cliente: Atención más rápida, productos disponibles, precios correctos y comprobantes electrónicos

Hitos
Hito 1: Diseño y Arquitectura; de requerimientos detallado, diagramas de arquitectura, modelo de datos (ERD), mockups de interfaces y especificación de APIs aprobados por el cliente.
Hito 2: Backend Core e Integración SUNAT: APIs funcionando, integración con SUNAT probada en ambiente de pruebas, modelos básicos de IA operativos, base de datos implementada.
Hito 3: Sistema Web Funcional: Todos los módulos principales del sistema web funcionando, integración frontend-backend completa, interfaz de usuario operativa.
Hito 4: POS Funcional: Aplicación POS de escritorio funcionando, integración con lectores de código de barras y impresoras, modo offline operativo.
Hito 5: IA Avanzada Completa: de recomendaciones, predicción de demanda y optimización funcionando, dashboard de predicciones disponible.
Hito 6: Sistema Completo Probado: Todos los módulos probados, integración con SUNAT validada, pruebas de rendimiento y seguridad aprobadas, bugs críticos corregidos.
Hito 7: Sistema en Producción: desplegado en producción, usuarios capacitados, documentación entregada, sistema operativo y estable.
Riesgos
Problemas de integración con SUNAT: Prototipo temprano, pruebas con ambiente de pruebas de SUNAT, múltiples proveedores OSE.
Rendimiento del POS con muchos productos: Optimización de consultas, índices, caché, pruebas de carga.
Problemas de conectividad en POS: Modo offline, sincronización diferida, manejo de errores robusto.
Escalabilidad de base de datos: Diseño escalable desde inicio, índices optimizados, arquitectura modular.
Cambios en requerimientos: Metodología ágil, comunicación constante, priorización de funcionalidades.
Retrasos en entregas: Buffer de tiempo, priorización, seguimiento semanal de avances.
Disponibilidad del equipo: Equipo dedicado, backup de conocimiento, documentación continua
Cambios en normativas SUNAT: Monitoreo de cambios, diseño flexible, actualizaciones periódicas.
Resistencia al cambio de usuarios: Capacitación adecuada, UI intuitiva, acompañamiento post-implementación.
Costos de infraestructura mayores: Monitoreo de uso, optimización, estimaciones conservadoras.
Problemas con OSE de SUNAT: Múltiples proveedores OSE, fallbacks, pruebas exhaustivas.
Complejidad de modelos de IA; Modelos simplificados inicialmente, iteración continua, validación con datos reales.
Costo Preliminar Estimado / Presupuesto
Proyecto de practicante con presupuesto mínimo (aprox. USD 30-122), utilizando recursos gratuitos y hardware propio.
La mayoría de herramientas son gratuitas (IDE, licencias educativas, servicios cloud en tier gratuito).
Hardware opcional (lector de código de barras y impresora térmica) puede ser proporcionado por el cliente.
El desarrollo es realizado por un practicante/estudiante como desarrollador único, lo que limita el alcance a funcionalidades core.

Supuestos
1. Disponibilidad de recursos: El equipo de desarrollo estará disponible durante las 14 semanas del proyecto sin interrupciones significativas.
2. Acceso a información: El cliente proporcionará acceso a información del negocio, procesos actuales y datos necesarios para el desarrollo.
3. Infraestructura: El cliente contará con o proporcionará acceso a infraestructura (servidores, base de datos) o se utilizará infraestructura en la nube según decisión del cliente.
4. Certificados SUNAT: El cliente contará con certificado digital y OSE (Operador de Servicios Electrónicos) configurado para facturación electrónica, o se proporcionará asesoría para su obtención.
5. Hardware POS: El cliente contará con o adquirirá el hardware necesario (computadora/tablet, lector de código de barras, impresora térmica) para el funcionamiento del POS.
6. Conectividad: El establecimiento contará con conexión a internet estable, aunque el POS funcionará en modo offline cuando sea necesario.
7. Participación del cliente: El cliente participará activamente en reuniones, validaciones y pruebas del sistema durante el desarrollo.
8. Normativas: Las normativas de SUNAT no cambiarán significativamente durante el desarrollo del proyecto (14 semanas).
9. Datos de prueba: Se contará con datos de prueba suficientes para entrenar los modelos de IA o se generarán datos sintéticos para desarrollo.
10. Capacitación: El cliente dedicará tiempo para la capacitación y adopción del sistema.
Restricciones
1. Tiempo: Duración fija de 14 semanas para completar el proyecto.
2. Presupuesto: Presupuesto limitado a USD 99,230, sin posibilidad de incrementos significativos sin aprobación formal.
3. Alcance: El alcance está limitado a los módulos definidos. Cualquier cambio o adición de funcionalidades requerirá aprobación formal y puede afectar tiempo y presupuesto.
4. Tecnologías: Uso de tecnologías específicas (React.js, Spring Boot, PostgreSQL, Python) definidas en la arquitectura. Cambios tecnológicos requerirían justificación y aprobación.
5. Normativas SUNAT: El sistema debe cumplir obligatoriamente con las normativas vigentes de SUNAT para facturación electrónica.
6. Protección de datos: El sistema debe cumplir con la Ley N° 29733 (Ley de Protección de Datos Personales) y normativas relacionadas.
7. Disponibilidad del equipo: El equipo está limitado a los roles definidos. Cambios en la composición del equipo requerirían aprobación.
8. Infraestructura: Dependiendo de la decisión del cliente (nube o local), puede haber restricciones de infraestructura que afecten el despliegue.
9. Hardware: El sistema POS está limitado a funcionar en hardware compatible con Electron (Windows, macOS, Linux).
10. Integraciones: Las integraciones están limitadas a SUNAT, lectores de código de barras e impresoras térmicas. Otras integraciones requerirían aprobación.
